مشروع COSULTA العملي — Appointment and Consultation Booking Web Application
التقنيات: PHP 8+ و MySQL و HTML/CSS. الواجهة عربية ومتجاوبة.

المتطلبات:
- XAMPP (Apache + MySQL) أو PHP و MySQL مثبتان.

طريقة التشغيل على Windows باستخدام XAMPP:
1) فك ضغط cosulta_practical.zip.
2) انسخ مجلد cosulta_practical إلى C:\xampp\htdocs\cosulta_practical
3) افتح XAMPP وشغّل Apache و MySQL.
4) افتح http://localhost/phpmyadmin
5) اختر Import واستورد الملف database.sql.
6) تأكد أن إعدادات config.php هي: قاعدة البيانات cosulta، المستخدم root، وكلمة المرور فارغة (وغيّرها إذا كانت مختلفة عندك).
7) افتح http://localhost/cosulta_practical/
8) أنشئي حساباً من صفحة التسجيل. اختاري Customer للحجز أو Provider لإضافة مواعيد.

إنشاء حساب المدير:
لأسباب أمنية، أنشئي حساباً عادياً أولاً ثم افتحي phpMyAdmin > قاعدة cosulta > جدول users، وغيّري role لحسابك إلى admin. بعدها سجلي الخروج والدخول من جديد.

طريقة تجربة السيناريو:
1) أنشئي حساباً، واجعلي حساباً من نوع Provider.
2) سجلي الدخول بحساب مقدم الخدمة، افتحي لوحة التحكم، وعدلي الملف وأضيفي موعداً مستقبلياً.
3) أنشئي حساباً آخر من نوع Customer، ابحثي عن مقدم الخدمة واحجزي الموعد.
4) افتحي حجوزاتي لمراجعة الحجز، ثم ادخلي بحساب المدير لمراجعة المستخدمين والحجوزات.

الوظائف المنفذة:
- تسجيل حساب ودخول وخروج مع تشفير كلمة المرور.
- أدوار Customer و Provider و Admin.
- البحث عن مقدمي الخدمة وعرض التخصص والسعر.
- مقدم الخدمة يعدل ملفه ويضيف ويحذف المواعيد المتاحة.
- حجز موعد ومنع حجز نفس الموعد مرتين، مع التحقق من الخادم.
- عرض حجوزات العميل وإلغاء الحجوزات المستقبلية.
- لوحة مدير لمراجعة الحسابات والحجوزات وتغيير حالة الحساب.
- سجل دفع تجريبي فقط؛ لا يوجد ربط ببوابة دفع حقيقية ولا يتم خصم أي أموال.

ملاحظة: المشروع نسخة عملية تعليمية قابلة للتطوير. قبل الاستخدام الحقيقي يجب تقوية إعدادات الأمان، وإضافة CSRF protection، وسياسة إلغاء واضحة، وربط بوابة دفع موثوقة، وإعدادات إنتاج ونسخ احتياطي.

إضافة Server-Driven UI (SDUI):
- الصفحة الرئيسية index.php لم تعد تكتب بطاقات مقدمي الخدمة مباشرة داخل PHP؛ بل تطلب مخطط الواجهة من api/ui.php بصيغة JSON.
- الخادم PHP يحدد مكونات الواجهة ويرسل البيانات القادمة من MySQL، وملف assets/js/sdui.js يحوّل المكونات المسموح بها إلى عناصر HTML.
- لتجربة الاستجابة، افتحي http://localhost/cosulta_practical/api/ui.php بعد تشغيل Apache وMySQL؛ ستظهر استجابة JSON تحتوي على ui.components.
- عند إضافة نوع مكوّن جديد، أضيفيه إلى المخطط في api/ui.php ثم أضيفي طريقة عرضه داخل renderComponent في assets/js/sdui.js.
- هذا تطبيق تعليمي لمفهوم Server-Driven UI؛ الأنواع غير المعروفة يتم تجاهلها، والنصوص تعرض باستخدام textContent لتجنب تفسيرها كـ HTML.
